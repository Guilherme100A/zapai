# General Guidelines

* Before implementing any feature, review the Leona Flow videos and/or research additional references about Leona Flow to understand how the feature works and how it should behave.

* Follow the existing milestones and tickets whenever they have been created. Implement them according to their real technical dependencies and do not skip required dependencies.

* Always test both the code and the UI before marking a milestone or ticket as completed.

* A milestone or ticket must not be considered complete until its implementation has been tested and the expected behavior has been verified.

* For videos, analyze both:

Video frames/screenshots to understand the UI, visual behavior, interactions, layouts, animations, and workflows.
Video text/transcript/audio-derived text to understand explanations, requirements, terminology, and behavior described verbally.
